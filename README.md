# AI Impact on Global Jobs Dashboard

## Project Overview
This Power BI dashboard analyzes the impact of Artificial Intelligence on global jobs.

The dashboard provides insights into:
- AI job trends
- Salary analysis
- Automation risk
- AI skill demand
- Industry AI adoption

---

## Tools Used
- Power BI
- Power Query
- Data Visualization

---

## Dashboard Features
- KPI Cards
- Line Chart
- Donut Chart
- Map Visualization
- Scatter Plot
- Treemap
- Interactive Filters

---

## Key Insights
- AI jobs are increasing rapidly
- High AI intensity jobs offer higher salaries
- AI skills are highly demanded
- Automation affects industries differently
